What is VNX?

The execution layer for AI agents.

AI models are great at answers, but real work still means copying context between chat, editor, Git and the browser. VNX sits above the models and tools and carries a task from goal to verified result.

You stay in control

Agents can act. You decide how much.

Every tool declares what it can do. A policy decides whether each action runs on its own, waits for your approval or is blocked.

  • Readfiles · git diff · ticketsAuto
  • Writeedit files · git commitApprove
  • Executenpm test · buildAuto if allowlisted
  • External actionsgit push · comment · emailApprove
  • Destructivedrop table · rm -rf · deploy prodBlock
Auto

Safe actions run on their own, so you are not clicking “yes” all day.

↓
Approve

Anything that changes your work waits for you, with the exact change shown.

↓
Block

Some actions never run, no matter what the model asks for.

Agents work inside a sandboxed workspace and never see raw secrets. Every step is recorded with its model, tokens, duration and cost.
