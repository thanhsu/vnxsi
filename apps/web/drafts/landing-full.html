The problem

AI is great at answers. You still do the work in between.

A real task crosses five tools, and you are the glue: copying context in, pasting results out, checking that nothing broke.

Today

ChatGPTcopy Claudecopy IDE→ Git→ Tracker→ Browser

Every hop loses context. Nobody records what was run, which model said what, or what it cost.

With VNX

Goal→ VNX→ Verified result

One goal in. VNX drives the models and tools, stops at the checkpoints you set, and hands back a result it has already checked.

How it works

From goal to verified result, with you at the checkpoints.

  1. Goal

    Describe the outcome in plain language.

  2. Plan

    VNX reads the context and breaks the work into steps.

  3. Approve

    You approve, edit or reject the plan before anything runs.

  4. Execute

    The agent works with real tools: files, Git, shell.

  5. Verify

    Tests and checks run before anything is called done.

  6. Result

    A summary, the diff, and a full record of every step.

Human in control

Agents act. Risky actions wait for you.

Every tool declares what it can do. A policy decides whether it runs on its own, asks first, or never runs at all.

LevelExample toolsDefault policy
READfilesystem.read · git.diff · git.statusAuto
WRITEfilesystem.write · git.commitApproval
EXECUTEshell.executeAuto if allowlisted Approval
EXTERNALgit.push · send email · post commentApproval
DESTRUCTIVEdatabase.drop · rm -rf · deploy prodBlocked

Agents run inside a workspace sandbox, never see raw secrets, and every decision lands in an audit log.

Model router · coming

The right model for each step, not the most expensive one for all.

Classifying a file doesn't need the same model as designing a migration. Pick a mode per project or per task.

Auto

VNX picks per step by task type.

Cheap

Smallest model that passes the checks.

Balanced

Strong models only where they matter.

Best

Top reasoning models throughout.

Local only

Nothing leaves your machine.

Roadmap

Built in small, working steps.

  1. v0.1 · now

    Developer Agent runtime

    Planner, executor, verifier, approvals, sandboxed file/Git/shell tools, timeline and cost tracking.

  2. v0.2

    Claude, OpenAI, Gemini and local models behind one router. Plug in any MCP server: GitHub, GitLab, Jira, browser.

    Schedules, triggers and webhooks. “Every morning at 8, check the open issues and send me a report.”
