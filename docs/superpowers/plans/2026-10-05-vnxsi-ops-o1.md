## Thiết kế chính

### Dữ liệu (`0013_ops_members.sql`)

```sql
CREATE TABLE ops_members (
  user_id    TEXT PRIMARY KEY REFERENCES users (id),
  role       TEXT NOT NULL CHECK (role IN ('operator', 'content', 'viewer')),
  granted_by TEXT NOT NULL REFERENCES users (id),
  granted_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE ops_member_invites (
  id          TEXT PRIMARY KEY,
  email       TEXT NOT NULL CHECK (email = lower(email)),
  role        TEXT NOT NULL CHECK (role IN ('operator', 'content', 'viewer')),
  created_by  TEXT NOT NULL REFERENCES users (id),
  status      TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'accepted', 'cancelled', 'expired')),
  expires_at  TEXT NOT NULL,          -- created_at + 7 ngày
  accepted_by TEXT REFERENCES users (id),
  created_at  TEXT NOT NULL,
  updated_at  TEXT NOT NULL
);
CREATE UNIQUE INDEX uq_ops_invite_pending ON ops_member_invites (email) WHERE status = 'pending';
```

- Không có giá trị `owner` trong bảng: Owner chỉ đến từ `ADMIN_EMAILS` (đơn giản hơn spec §3.3; Owner gốc không thể bị hạ bằng dữ liệu).
- `users.is_admin` cũ không còn là nguồn quyền cho Ops; giữ cột (không migration xóa).

### Ma trận capability (hàm thuần `can(role, capability)`)

`overview.view`, `overview.detail` (không cho Content), `audit.view`, `marketplace.view`, `marketplace.act`, `users.view`, `users.act`, `feedback.view`, `feedback.act`, `team.manage` (chỉ Owner), `settings.act` (Owner), `monetization.view`/`monetization.act` (Owner), `content.view`/`content.act` (dự phòng cho O3, chưa có route). Mỗi route khai báo đúng một capability; test bảng cho cả 4 vai trò × mọi capability.

### Hợp đồng 404 kín

Một hàm `opsNotFound(c)` duy nhất cho mọi trường hợp từ chối, cùng status, body và header với 404 thật của `/ops/*`. Test so sánh byte-by-byte (trừ request id) giữa: chưa đăng nhập, bị khóa, không vai trò, thiếu capability, route không tồn tại.

### Overview (O1)

Hàng chờ đọc trực tiếp từ bảng hiện có, mỗi hàng một truy vấn `COUNT` + `MIN(created_at)`: builder `pending`, product `in_review`, feedback `new` (+ số chưa gửi mail), request chờ ghép (theo state machine M6), Inquiry quá hạn (theo luật nhắc/báo của M5). Không thêm bảng thống kê. Dòng "Counts read at {UTC}". Content: chỉ số, không link, không ID.
